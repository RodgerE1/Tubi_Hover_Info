Tubi Hover Info

Movie and show details, one hover away.

Use Opera or Opera GX for the easiest setup.

Hover details include the synopsis, cast, director, year, runtime, rating, genres, and an optional TMDB score when Tubi/TMDB provide them.

Install in Opera / Opera GX

  1. Keep this extracted folder somewhere permanent.
  2. Type opera://extensions in Opera's address bar.
  3. Turn on Developer mode.
  4. Select Load unpacked.
  5. Select this folder: packages\Opera
  6. Refresh Tubi and hover over a movie or show.

Optional TMDB score

Open the extension's toolbar button, paste your TMDB API Key into the TMDB field, and click outside the field to save it. Use the short API Key—not the long API Read Access Token. The key stays in this browser and must not be committed to GitHub.

Read at your own pace

Move into the panel to read it, select Pin to keep it open, or press Esc to close. The extension's toolbar button changes hover delay, text size, poster artwork, and the optional TMDB key.

Firefox 128 or newer

Open about:debugging#/runtime/this-firefox, select Load Temporary Add-on, and choose packages\Firefox\manifest.json. Firefox removes this unsigned test add-on when it restarts.
